# Release 安装入口实施计划

**目标：** 发布可下载的 RN02 面板安装包与交互式安装入口，整合用户在 `stest/XiaoMi-BE6500-SSH` 验证的 SSH 开启脚本。
**架构：** 宿主机脚本提供两个入口。未取得 SSH 时，使用已登录后台的 STOK 和固定支持固件完成原厂 SSH 开启流程；已取得 SSH 时，通过现有 SSH 会话安装经过 SHA256 校验的 Release 包。不改变现有路由器 WAN/Wi-Fi/代理开关。
