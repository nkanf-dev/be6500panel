# 真实 PTY 终端实施计划

**目标：** 为已认证单人面板提供 xterm.js 交互终端，支持实际终端中断、作业控制和尺寸变化。
**架构：** Rust 管理器按显式打开请求创建 PTY 会话与 `/bin/ash`，设置控制终端、会话/前台进程组及 `TERM=xterm-256color`。复用现有认证和单监听，不另起 ttyd/SSH/WebSocket 守护服务。字节流与 resize 通过认证通路传送，输出有界，断开/退出会回收相关进程。

- [ ] 定义 PTY 会话输入/输出/resize/关闭契约；认证及 native-only，限制活动会话数量，读页面不启动 Shell。
- [ ] 实现实际 PTY、控制终端、非阻塞读写、前台作业控制和断开后的进程回收；测试 Ctrl+C/D/Z、winsize、TERM、交互回显与退出，不模拟成功。
- [ ] UI 专家接入 xterm.js/fit，系统终端 Tab，明确连接/退出，快捷键原字节，页面卸载关闭，不保存命令/密钥。
- [ ] 串行 Rust/Linux/ARM 与前端/browser 测试，通过后受控更新唯一生产服务，验证真实简单交互，不执行网络破坏命令。
