# BE6500 管理器实测

同一台 BE6500，保留相同配置和数据。测试使用同一台客户端、相同认证方式和 11 个串行只读接口，每个接口预热一次、测量 10 次。

## 资源

| 指标 | 原管理器 | Rust 管理器 |
| --- | ---: | ---: |
| 管理器 RSS | 15,660 KiB | 5,844 KiB |
| 管理器线程 | 13 | 2 |
| 发布包 | 4,448,072 bytes | 3,411,448 bytes |

管理器 RSS 降低 **62.7%**，发布包减少 **23.3%**。RSS 不包含独立的 sing-box 核心。整机可用内存由 44,548 KiB 变为 83,004 KiB；该变化同时包含核心重启后的内存状态、旧程序和临时验收目录清理，不全部归因于管理器重写。

## API 延迟

| 接口 | 原版中位数 ms | Rust 中位数 ms |
| --- | ---: | ---: |
| `/api/health` | 4.78 | 9.40 |
| `/api/runtime` | 5.42 | 10.86 |
| `/api/proxy/nodes` | 38.64 | 44.27 |
| `/api/proxy/local-rules` | 超时，无有效样本 | 131.22 |
| `/api/system` | 5.50 | 7.76 |
| `/api/router` | 8.78 | 18.37 |
| `/api/modules` | 5.02 | 13.77 |
| `/api/system/services` | 9.37 | 19.07 |
| `/api/proxy/metrics` | 17.55 | 10.58 |
| `/api/traffic/history?range=3h&maxPoints=300` | 20.71 | 58.01 |
| `/api/devices/activity?range=24h&maxPoints=288&limit=32&search=` | 10.49 | 23.50 |

本轮 Rust 110 次测量均成功。原版规则接口连续超时；其他原版接口有有效延迟样本。多数 Rust 接口中位延迟仍高于原版，因此不能声称全面提速。代理遥测读取更快，管理器内存和线程数更少。

实际计数、活动连接和历史覆盖会随时间改变，响应大小不是完全固定。10 个样本的 P95 只反映本次短测，不作为长期 SLA。旧版未记录相同区间的 CPU 或启动时间，不能给出这些指标的提升百分比。
