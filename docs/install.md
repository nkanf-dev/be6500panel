## 发布资产与完整性校验

项目 Releases 提供两个核心打包文件与散列清单：

| 文件名 | 内容与用途说明 |
| :--- | :--- |
| `be6500panel-installers.tar.gz` | 本地安装引导工具包（包含 `install.sh`、`install.ps1`、`enable-ssh.*`、`install-panel.*`） |
| `be6500panel-armv7.tar.gz` | 路由器端运行时包（包含 ARMv7 静态二进制、Web 静态资源与引导配置） |
| `SHA256SUMS` | 资产包 SHA256 完整性校验清单 |

### 下载与校验步骤

1. 在连接路由器局域网的电脑上新建工作目录，下载上述三个文件并放于同一文件夹内；
2. 在终端核对文件完整性：
   ```bash
   sha256sum -c SHA256SUMS
   ```
3. 解压安装工具包（确保解压出的脚本文件与 `be6500panel-armv7.tar.gz` 位于同级目录）：
   ```bash
   tar -xzf be6500panel-installers.tar.gz
   ```

## 固件与环境支持

- **适用机型**：小米路由器 BE6500（硬件代号：RN02，高通 IPQ5322 四核平台）。
- **SSH 开启工具**：适用于官方原厂固件 **1.0.42** 与 **1.0.43**。
- **面板运行环境**：支持小米路由器 BE6500 已具备 SSH 访问权限的环境，项目持续跟进官方固件更新并进行维护适配。
- **初始 root 密码说明**：SSH 开启工具基于机身底座 SN（序列号）与原厂算法推算默认初始密码；若此前已在路由器后台自行修改过 root 密码，请使用修改后的密码登录。
- **空间要求**：路由器 `/data` 分区只需保留 ≥ 1MiB 可用空间（运行时部署至 `/tmp` 内存中，不长期挤占持久闪存）。

## 路径一：尚未取得 SSH 的设备（开启 SSH 并安装）

适用于运行固件 1.0.42 或 1.0.43 且未开通 SSH 的设备。所有操作在局域网电脑终端执行。

### 步骤 1：获取后台鉴权值 (stok)

1. 使用电脑浏览器登录路由器管理后台（默认地址：`http://192.168.31.1`）；
2. 登录成功后，复制浏览器地址栏 URL 中的 `stok` 参数值（例如：`http://192.168.31.1/cgi-bin/luci/;stok=abcdef0123456789/...` 中的 `abcdef0123456789`）。

### 步骤 2：执行安装引导

在本地电脑终端进入解压目录，运行：

```bash
# macOS / Linux:
sh install.sh

# Windows (PowerShell):
.\install.ps1
```

- 选择 `1` 进入 SSH 开启流程；
- 按照屏幕提示依次输入：
  1. 路由器局域网 IP（回车默认 `192.168.31.1`）；
  2. 设备机身底座铭牌上的 SN 序列号；
  3. 步骤 1 获取的 `stok` 字符串。
- 工具将自动调用原厂接口启动 Dropbear SSH 服务，并在终端给出推算的初始 root 密码。

### 步骤 3：验证登录并部署面板

新开终端测试 SSH 连通性：

```bash
ssh root@192.168.31.1
```

输入密码确认成功进入路由器终端后，返回安装引导输入 `y` 继续，脚本将自动调用 `install-panel` 完成面板部署，并提示为面板设置独立控制台密码。

## 路径二：已有 SSH 访问权限的设备（直接安装）

适用于此前已具备 SSH 访问权限的设备。在电脑终端进入解压目录执行：

```bash
# 方式 A：交互式引导（选择 2）：
sh install.sh
# Windows: .\install.ps1

# 方式 B：直接执行部署工具并指定路由器 IP：
# macOS / Linux:
sh install-panel.sh --host 192.168.31.1

# Windows (PowerShell):
.\install-panel.ps1 -Router 192.168.31.1
```

安装脚本将自动执行以下流程：
1. **环境检查**：确认目标设备架构为 ARMv7，检查空间与已有配置；
2. **完整性校验**：通过 SSH 将 `be6500panel-armv7.tar.gz` 传输至路由器，并在设备端核对 SHA256 散列；
3. **独立密码设置**：若为首次安装，提示在终端输入并确认**面板独立的控制台密码**（非路由器后台密码）；
4. **服务部署就绪**：将运行时与静态资源解压至 `/tmp/be6500panel/boot-release/`，持久包归档至 `/data/be6500panel/panel.tar.gz`，配置自启引导并启动服务（监听本地端口 `8787`）。

## 访问控制面板

安装完成后，在浏览器中打开：

```text
http://192.168.31.1:8787/
```

- 若此前修改过局域网 IP，请替换为当前的实际网关 IP；
- 首次登录使用安装部署时设定的**面板控制台密码**；
- 服务状态可在控制台中的系统与服务页面实时查看与管理。

---

## 独立救援通道

若因意外配置导致主 SSH 端口无法连接，面板支持独立的救援通道服务：

```bash
# 通过 2222 端口并指定私钥登录独立救援通道
ssh -p 2222 -i <identity_key> root@192.168.31.1
```
