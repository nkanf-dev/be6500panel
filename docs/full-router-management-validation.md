# 统一路由管理验收

当前固件契约以 RN02 1.0.64 为准。后端、前端和原厂单次 helper 共用现有认证与串行操作通道，没有新增常驻服务。

## 已验证
- 694 项 Rust 测试、静态检查与 ARM 静态构建通过。
- 1626 项前端测试、25 项浏览器流程与生产前端构建通过。
- 真机读取走查覆盖 85 项视图记录，包括带参数的端口服务、两个无线频段与未配置 DDNS 服务商查询。已执行的读取未出现可见告警、页面异常或 API 失败。
- 真机核对 LAN 地址与掩码、WAN 参数和 LED 开关与定时表单的实际预填。
- 路由器名称同值保存完成并读回一致；指示灯关闭、读回与原设置恢复完成；计划重启保持关闭并成功保存。
- 中断操作通过持久化记录恢复。监听切换、刷新后恢复待确认任务、明确升级拒绝与非刷写失败收尾、家长控制精确恢复由合成测试覆盖。

## 验收边界
没有为了验收改变家庭 WAN/LAN 模式、无线设置，也未执行重启、恢复出厂或固件刷写。无已配置用户或节点身份的家长控制、Mesh 状态查询没有冒充真机操作通过。

官方升级接入原厂固定官方下载、哈希与镜像校验及安全启动检查流程，不提供任意 URL 或自定义刷机输入。刷写与恢复出厂不能通过 UCI 快照撤销。

压缩发布包为 3,674,561 字节。临时实例的资源测量是服务关闭、复制数据的条件快照，不能作为完整生产资源收益或全服务容量保证。最终生产测量另行记录。
